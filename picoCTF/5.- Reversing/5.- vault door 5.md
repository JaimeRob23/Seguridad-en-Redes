## Soluciones
Aquí el truco es invertir dos transformaciones:

1. `Base64`
2. `URL Encoding`

El código hace esto:

```
password→ urlEncode()→ base64Encode()→ comparar con expected
```

Entonces nosotros hacemos lo contrario:

```
expected→ Base64 decode→ URL decode→ password original
```

## Paso 2 — URL Decode

Cada `%xx` es hexadecimal ASCII.

Por ejemplo:

```
%63 = c%30 = 0%6e = n
```

y así sucesivamente.

Resultado final:

```
c0nv3rt1ng_fr0m_ba5e_64_7f855fc5
```
