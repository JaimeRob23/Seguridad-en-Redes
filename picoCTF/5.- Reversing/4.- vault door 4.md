The source code for this vault is here: [VaultDoor4.java](https://challenge-files.picoctf.net/c_fickle_tempest/3af806b1d880a4a7cecd00831a8bcc913cf57c68cb7f5cfb8597f710c5d771e1/VaultDoor4.java)

## Solucion
Este reto es más fácil: el password está escondido en distintos formatos numéricos.

El arreglo importante es:

```
byte[] myBytes = {    106 , 85  , 53  , 116 , 95  , 52  , 95  , 98  ,    0x55, 0x6e, 0x43, 0x68, 0x5f, 0x30, 0x66, 0x5f,    0142, 0131, 0164, 063 , 0163, 0137, 061 , 063 ,    'd' , 'f' , '6' , '1' , '8' , 'a' , '2' , '3' ,};
```

Hay números en:

- decimal
- hexadecimal (`0x`)
- octal (`0142`)
- caracteres (`'d'`)

Todo eso representa bytes ASCII.

---

## Convertimos cada parte

### Decimal

```
106 = j85  = U53  = 5116 = t95  = _52  = 495  = _98  = b
```

Resultado:

```
jU5t_4_b
```

---

### Hexadecimal

```
0x55 = U0x6e = n0x43 = C0x68 = h0x5f = _0x30 = 00x66 = f0x5f = _
```

Resultado:

```
UnCh_0f_
```

---

### Octal

```
0142 = b0131 = Y0164 = t063  = 30163 = s0137 = _061  = 1063  = 3
```

Resultado:

```
bYt3s_13
```

---

### Caracteres directos

```
df618a23
```
